# 硬體說明：16GB VRAM＋32GB RAM

> **狀態：2026-10-07 在 RTX 5090 上模擬驗證過。** 模擬方式：
> - 顯存：另開程式佔住，ComfyUI 只剩約 14.6GB（比真實 16GB 卡扣掉桌面後還少一點）。
> - 記憶體：**這台電腦平常的程式照常開著**，再另外鎖住記憶體，讓整台實際只剩「32GB 扣掉常駐程式」的量；同時讓 ComfyUI 以為總記憶體只有 32GB（它的釘選量、卸載判斷會照 32GB 走）。常駐程式分兩種假設：8GB（只開必要程式）與 **12GB（開著瀏覽器、通訊軟體，較接近一般使用）**。
>
> 驗證的是「每個本地模型能不能跑、輸出會不會變、要多少記憶體」；**真實 16GB 卡的速度沒有實測**（見「預估耗時」）。測試程式與原始數據：[setup/16gb_sim/](../setup/16gb_sim/)。

適用：RTX 4080／5070 Ti／5080 16GB＋32GB 系統記憶體＋NVMe SSD。記憶體 64GB 的請改用 [shanshiba-workflow-16gvram-64gram](https://github.com/mathruffian-dot/shanshiba-workflow-16gvram-64gram)（比較寬裕）。

## 一句話

**能跑完整工作流，模型和完整版一模一樣，出來的東西幾乎完全相同；代價是 H3 慢 8–25%，而且記憶體非常緊——生成時整台電腦只能做這件事。**

### 角色 LoRA 訓練（選用）

在同樣的模擬條件下用 AI Toolkit 訓練 1600 步：**33 分鐘、顯存峰值 14.7GB、記憶體最低剩 0.5GB**。能跑完，但記憶體幾乎用光——訓練時一定要關掉瀏覽器等所有其他程式。真實 16GB 卡推估約 1–1.5 小時。詳見 `setup/lora/README.md`。

### H3 再細看（兩種常駐假設）

| 常駐程式 | 鏡頭 | 秒數 | 比不設限慢 | 記憶體最低剩 | 畫面 |
|---|---|---|---|---|---|
| 8GB | 對白中景 158 格 | 84.3 | +8% | 6.6GB | PSNR 38.9 dB（只有手的位置微差，表演與臉相同） |
| 8GB | 雙人近景 107 格 | 61.9 | +25% | 7.1GB | 逐格相同 |
| 12GB | 對白中景 158 格 | 84.1 | +8% | 3.3GB | 同上 |
| 12GB | 雙人近景 107 格 | 62.1 | +25% | 3.7GB | 逐格相同 |

- 32GB 時 ComfyUI 會自動改成「邊跑邊從硬碟讀模型」（每鏡讀約 58–61GB），所以硬碟一定要是 NVMe。加 `--fast-disk` 沒有差別。
- 分頁檔幾乎沒用到（約 1GB），慢是因為從硬碟讀模型，不是記憶體交換。

### 試過、不建議的

| 做法 | 結果 |
|---|---|
| 換較小的 NVFP4 文字編碼器＋int8 VAE | 記憶體反而更緊（最低剩 1.1GB），而且同 seed 結果會變、在不同記憶體條件下也不固定 |
| GGUF Q4 主模型 | 沒測；H3 的張量寬度做不了真正的 K 量化，畫質損失沒人實測 |

## 設定

| 項目 | 值 |
|---|---|
| 設定檔 | `call configs\profile.cmd` |
| 模型 | **跟完整版完全一樣**（H3 剪枝 int8、文字編碼器 int8、影片 VAE fp16、DMAD 4 步） |
| ComfyUI 啟動參數 | `--reserve-vram 1.5`（`profile.cmd` 已設）；VAE 解碼當機再加 `--disable-pinned-memory --disable-async-offload` |
| 單鏡長度 | ≤12 秒（260 格在 16GB 顯存下實測可跑） |
| 原生 1080p／H3 兩段精修 | 不要用 |
| 放大 | 近景 RTX VSR、全景 FlashVSR |
| 分頁檔 | Windows 預設「系統管理」（會自動長大）；**不要設成固定的小數字**。推估真實 32GB 電腦生成時需要約 50GB 虛擬記憶體，分頁檔至少要能長到 20GB |
| 硬碟 | NVMe SSD（模型邊跑邊從硬碟讀） |

## 一定要遵守

1. **一次只跑一件 GPU 工作**：配音、生圖、H3、放大不要同時（`run_queue.sh` 已經會等 GPU 空）。
2. **生成時關掉瀏覽器、遊戲、剪輯軟體**。常駐程式超過 12GB 就可能開始變慢或失敗。
3. 第一次裝好先跑 `setup\smoke_test.py`，確認全部 OK 再做片。

## 預估耗時（未實測）

5090 上量到的秒數不能直接當真實 16GB 卡的速度：16GB 卡算力約 5090 的四到五成（依 NVIDIA 公開規格粗估），32GB 記憶體還要邊跑邊從硬碟讀。

| 工作 | 5090 上本配置實測 | 真實 16GB 卡推估 |
|---|---|---|
| 首幀一張（Qwen 2K、50 步） | 約 1 分鐘 | 約 2–3 分鐘 |
| 5 秒鏡（124 格）DMAD | 約 1.2 分鐘 | 約 2.5–3.5 分鐘 |
| 一支 40 鏡的片（H3 部分） | 約 50 分鐘 | 約 2–2.5 小時 |
| 首幀審過到成片 | — | 約半天（可過夜） |

## 這次驗證不到的

1. 真實速度（見上）、PCIe 4.0 的 4080 搬資料較慢。
2. 硬碟速度：這台是高速 NVMe；SATA SSD 會明顯變慢，傳統硬碟不建議。
3. 真實卡的驅動問題（社群 2026-08 回報 50 系列 16GB 卡在 Windows 的黑畫面、VAE 記憶體錯誤，見完整版文件）。
4. 模擬時分頁檔的起始大小跟真實 32GB 電腦不同。
